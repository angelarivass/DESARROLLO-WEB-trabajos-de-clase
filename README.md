# Web Development Coursework

A collection of assignments and exercises developed for the Web Development course, part of the Software Engineering program at CETYS Universidad.

## Structure

The repository is organized by academic term (partial exam periods):

- **Parcial1**: exercises and assignments from the first grading period.
- **Parcial2**: exercises and assignments from the second grading period.
- **Parcial3**: exercises and assignments from the third grading period.

## Technologies Used

- JavaScript
- HTML
- CSS

## Purpose

This repository documents progressive, hands-on practice with front-end web development fundamentals, including page structure, styling, and client-side interactivity.
